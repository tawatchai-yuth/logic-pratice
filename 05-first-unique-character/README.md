# ข้อ 5: First Unique Character — หาตัวอักษรตัวแรกที่ไม่ซ้ำ

## ระดับ
ง่าย–ปานกลาง

## โจทย์
เขียนฟังก์ชัน `firstUniqueChar(value: string): string | null` เพื่อหาตัวอักษรตัวแรกที่ปรากฏในข้อความเพียงครั้งเดียวเท่านั้น หากไม่มีให้คืนค่า `null`

เงื่อนไข:
- แยกตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ เช่น `A` กับ `a` ถือเป็นคนละตัวอักษร
- ต้องคืนตัวอักษรตามลำดับที่ปรากฏในข้อความเดิม

## ตัวอย่างผลลัพธ์

```ts
firstUniqueChar("leetcode")  // "l"
firstUniqueChar("loveleetcode") // "v"
firstUniqueChar("aabbcc")    // null
firstUniqueChar("swiss")     // "w"
firstUniqueChar("")          // null
firstUniqueChar("aAb")       // "a"
```

## คำอธิบายแนวคิด
ตัวอย่าง `"loveleetcode"`:
- `l` ปรากฏหลายครั้ง
- `o` ปรากฏหลายครั้ง
- `v` ปรากฏครั้งเดียว และเป็นตัวแรกที่เข้าเงื่อนไข

วิธีที่ทำความเข้าใจง่ายคือวนรอบแรกเพื่อเก็บจำนวนครั้งที่แต่ละตัวอักษรปรากฏด้วย `Map` จากนั้นวนข้อความอีกรอบเพื่อหาตัวแรกที่มีจำนวนเท่ากับ `1`

## สิ่งที่ควรฝึก
- การนับความถี่ด้วย `Map`
- การวนข้อมูลสองรอบ
- การคืนค่าเมื่อไม่พบคำตอบ
