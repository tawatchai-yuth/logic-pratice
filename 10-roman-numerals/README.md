# ข้อ 10: Roman Numerals — แปลงเลขอารบิกและเลขโรมัน

## ระดับ
ปานกลาง

## โจทย์
เขียนฟังก์ชัน 2 ฟังก์ชัน:
- `toRoman(number: number): string` แปลงจำนวนเต็มบวกเป็นเลขโรมัน
- `fromRoman(roman: string): number` แปลงเลขโรมันเป็นจำนวนเต็ม

ใช้สัญลักษณ์ `I=1`, `V=5`, `X=10`, `L=50`, `C=100`, `D=500`, `M=1000` และรูปแบบลบ เช่น `IV=4`, `IX=9`, `XL=40`, `XC=90`, `CD=400`, `CM=900`

สำหรับชุดฝึกนี้ให้รองรับจำนวนเต็มตั้งแต่ 1 ถึง 3999 และถือว่า input ของ `fromRoman` เป็นเลขโรมันรูปแบบมาตรฐานที่ถูกต้อง

## ตัวอย่างผลลัพธ์

```ts
toRoman(1989)       // "MCMLXXXIX"
toRoman(2000)       // "MM"
toRoman(68)         // "LXVIII"
toRoman(109)        // "CIX"

fromRoman("MCMLXXXIX") // 1989
fromRoman("MM")        // 2000
fromRoman("LXVIII")    // 68
fromRoman("CIX")       // 109
```

## คำอธิบายแนวคิด
การแปลงเป็นเลขโรมัน ใช้รายการค่าจากมากไปน้อย เช่น `1000 → M`, `900 → CM`, `500 → D`, `400 → CD` แล้ววนเลือกค่าที่นำไปหักจากจำนวนที่เหลือได้

การแปลงกลับ ให้อ่านค่าของสัญลักษณ์ทีละตัว หากค่าปัจจุบันน้อยกว่าค่าถัดไป ให้ลบค่าปัจจุบัน มิฉะนั้นให้บวกค่า เช่น `IV` คำนวณเป็น `-1 + 5 = 4`
