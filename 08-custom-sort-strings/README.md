# ข้อ 8: Custom Sort — เรียงรหัสตามตัวเลขที่อยู่ในข้อความ

## ระดับ
ปานกลาง

## โจทย์
เขียนฟังก์ชัน `sortCodes(codes: string[]): string[]` เพื่อเรียงรหัสตามตัวเลขที่อยู่ในรหัส โดยเรียงตัวเลขจากน้อยไปมาก หากตัวเลขเท่ากัน ให้เรียงตามตัวอักษรของรหัส

สำหรับชุดฝึกนี้ กำหนดให้รหัสแต่ละรายการมีตัวอักษรนำหน้าและมีตัวเลขอย่างน้อยหนึ่งหลัก เช่น `TH19`, `SG20`, `TH2`

## ตัวอย่างผลลัพธ์

```ts
sortCodes(["TH19", "SG20", "TH2"])
// ["TH2", "TH19", "SG20"]

sortCodes(["TH10", "TH3Netflix", "TH1", "TH7"])
// ["TH1", "TH3Netflix", "TH7", "TH10"]

sortCodes(["A12", "B2", "C2"])
// ["B2", "C2", "A12"]

sortCodes([])
// []
```

## คำอธิบายแนวคิด
ต้องดึงตัวเลขออกจากรหัสแล้วแปลงเป็น `number` ก่อนเปรียบเทียบ ไม่ควรเรียงเป็นข้อความตรง ๆ เพราะ `"19"` อาจถูกเรียงก่อน `"2"` เมื่อเปรียบเทียบแบบตัวอักษร

ตัวอย่าง `"TH2"` มีค่าตัวเลข `2` ส่วน `"TH19"` มีค่าตัวเลข `19` ดังนั้น `"TH2"` ต้องมาก่อน

หากค่าตัวเลขเท่ากัน ให้ใช้ `localeCompare()` หรือกฎเรียงลำดับรองที่กำหนดไว้

## สิ่งที่ควรฝึก
- `Array.sort()`
- การดึงตัวเลขจาก String
- Comparator
- การกำหนดเงื่อนไขเรียงลำดับรอง
