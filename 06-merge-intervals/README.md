# ข้อ 6: Merge Intervals — รวมช่วงตัวเลขที่ทับซ้อนกัน

## ระดับ
ปานกลาง

## โจทย์
เขียนฟังก์ชัน `mergeIntervals(intervals: [number, number][]): [number, number][]` เพื่อรวมช่วงตัวเลขที่ทับซ้อนกัน โดยแต่ละช่วงอยู่ในรูป `[start, end]`

ให้ถือว่าช่วง `[1, 4]` และ `[4, 5]` ทับซ้อนหรือเชื่อมต่อกัน และสามารถรวมเป็น `[1, 5]` ได้

## ตัวอย่างผลลัพธ์

```ts
mergeIntervals([[1, 3], [2, 6], [8, 10], [15, 18]])
// [[1, 6], [8, 10], [15, 18]]

mergeIntervals([[1, 4], [4, 5]])
// [[1, 5]]

mergeIntervals([[5, 7], [1, 2], [2, 4]])
// [[1, 4], [5, 7]]

mergeIntervals([])
// []
```

## คำอธิบายแนวคิด
ขั้นแรกเรียงช่วงตามค่า `start` จากน้อยไปมาก จากนั้นพิจารณาทีละช่วง:
- ถ้าผลลัพธ์ยังว่าง ให้เพิ่มช่วงแรก
- ถ้าจุดเริ่มต้นของช่วงใหม่ไม่เกินจุดสิ้นสุดของช่วงล่าสุด ให้รวมช่วง โดยใช้จุดสิ้นสุดที่มากกว่า
- ถ้าไม่ทับซ้อนกัน ให้เพิ่มเป็นช่วงใหม่

ตัวอย่าง `[1, 3]` กับ `[2, 6]` ทับซ้อนกัน จึงรวมเป็น `[1, 6]`

## สิ่งที่ควรฝึก
- การเรียงลำดับ array
- การเปรียบเทียบช่วง
- การอัปเดตสมาชิกตัวล่าสุดในผลลัพธ์
- การจัดการ input ว่าง
