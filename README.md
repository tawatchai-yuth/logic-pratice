# Logic Practice — แบบฝึกหัดฝึก Logic

โจทย์รวมทั้งหมด 12 ข้อ

## โจทย์
1. `07-balanced-brackets` — ตรวจสอบวงเล็บเปิด–ปิดให้ครบคู่
2. `08-custom-sort-strings` — เรียงรหัสตามตัวเลขในข้อความ
3. `09-autocomplete` — ระบบแนะนำคำจากคำค้นหา
4. `10-roman-numerals` — แปลงเลขอารบิกและเลขโรมัน
5. `11-largest-number-from-digits` — เรียงตัวเลขจากมากไปน้อย
6. `12-tribonacci` — สร้างลำดับจากผลรวม 3 ค่าก่อนหน้า
7. `01-two-sum` — หาคู่ตัวเลขที่รวมกันได้ตามเป้าหมาย
8. `02-palindrome` — ตรวจสอบข้อความกลับหน้าแล้วเหมือนเดิม
9. `03-run-length-encoding` — ย่อข้อความที่มีตัวอักษรซ้ำติดกัน
10. `04-flatten-array` — แปลง array ซ้อนกันให้เป็น array ชั้นเดียว
11. `05-first-unique-character` — หาตัวอักษรตัวแรกที่ไม่ซ้ำ
12. `06-merge-intervals` — รวมช่วงตัวเลขที่ทับซ้อนกัน

## รูปแบบไฟล์

แต่ละโฟลเดอร์มีไฟล์ `README.md` ซึ่งประกอบด้วยโจทย์ เงื่อนไข ตัวอย่างผลลัพธ์ คำอธิบายแนวคิด และสิ่งที่ควรฝึก โดยไม่ได้ใส่เฉลยโค้ด เพื่อให้ใช้ฝึกเขียนฟังก์ชันด้วยตัวเอง
