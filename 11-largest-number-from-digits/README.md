# ข้อ 11: Largest Number — เรียงตัวเลขให้ได้ค่ามากที่สุด

## ระดับ
ง่าย

## โจทย์
เขียนฟังก์ชัน `largestFromDigits(value: number): number` รับจำนวนเต็มบวก แล้วเรียงตัวเลขแต่ละหลักจากมากไปน้อยเพื่อสร้างจำนวนใหม่

เงื่อนไข:
- รับจำนวนเต็มบวก
- เก็บตัวเลขทุกหลัก รวมถึงหลักที่ซ้ำกัน
- คืนผลลัพธ์เป็น `number`

## ตัวอย่างผลลัพธ์

```ts
largestFromDigits(3008) // 8300
largestFromDigits(1989) // 9981
largestFromDigits(2679) // 9762
largestFromDigits(9163) // 9631
largestFromDigits(5551) // 5551
```

## คำอธิบายแนวคิด
แปลงตัวเลขเป็น String เพื่อแยกแต่ละหลัก จากนั้นเรียงตัวเลขจากมากไปน้อย แล้วนำมาต่อกันและแปลงกลับเป็น Number

ตัวอย่าง `1989` มีหลัก `1, 9, 8, 9` เมื่อเรียงจากมากไปน้อยจะได้ `9, 9, 8, 1` จึงคืนค่า `9981`

## สิ่งที่ควรฝึก
- การแปลง Number และ String
- การเรียงลำดับตัวเลข
- การต่อ String
