# ข้อ 1: Two Sum — หาคู่ตัวเลขที่รวมกันได้ตามเป้าหมาย

## ระดับ
ง่าย–ปานกลาง

## โจทย์
เขียนฟังก์ชัน `twoSum(numbers: number[], target: number): number[]` เพื่อหาตำแหน่ง (index) ของตัวเลข 2 ตัวใน array ที่เมื่อนำมาบวกกันแล้วได้ค่าเท่ากับ `target`

เงื่อนไข:
- ให้คืนค่า index ของตัวเลขทั้งสองตำแหน่ง
- ใช้ index เริ่มต้นที่ `0`
- รับประกันว่ามีคำตอบเพียงหนึ่งคู่
- ห้ามใช้สมาชิกตำแหน่งเดียวกันซ้ำสองครั้ง

## ตัวอย่างผลลัพธ์

```ts
twoSum([2, 7, 11, 15], 9)       // [0, 1]
twoSum([3, 2, 4], 6)            // [1, 2]
twoSum([3, 3], 6)               // [0, 1]
twoSum([-1, 8, 4, 2], 6)        // [1, 3]
```

## คำอธิบายแนวคิด
ตัวอย่าง `[2, 7, 11, 15]` และ `target = 9` ต้องหาเลขสองตัวที่รวมกันได้ 9 คือ `2 + 7` ซึ่งอยู่ที่ index `0` และ `1`

แนวทางหนึ่งคือวนดูตัวเลขแต่ละตัว แล้วคำนวณค่าที่ต้องการเพิ่มให้ครบเป้าหมายด้วย `target - current` จากนั้นค้นหาว่าเคยพบค่านั้นแล้วหรือยัง อาจใช้ `Map` เพื่อให้ค้นหาได้รวดเร็ว

## สิ่งที่ควรฝึก
- การวนลูป array
- การใช้ index
- การใช้ `Map` หรือการค้นหาคู่ตัวเลข
- การคิดกรณีที่มีตัวเลขซ้ำ
