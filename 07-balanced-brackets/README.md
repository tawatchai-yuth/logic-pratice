# ข้อ 7: Balanced Brackets — ตรวจสอบวงเล็บเปิด–ปิด

## ระดับ
ปานกลาง

## โจทย์
เขียนฟังก์ชัน `isBalanced(value: string): boolean` เพื่อตรวจสอบว่าสัญลักษณ์วงเล็บ `()`, `[]`, `{}` เปิดและปิดครบคู่ตามลำดับที่ถูกต้องหรือไม่

เงื่อนไข:
- รองรับเฉพาะ `(`, `)`, `[`, `]`, `{`, `}`
- วงเล็บปิดต้องตรงกับวงเล็บเปิดตัวล่าสุด
- หากมีวงเล็บปิดก่อนวงเล็บเปิด หรือมีวงเล็บเหลืออยู่ ให้คืนค่า `false`

## ตัวอย่างผลลัพธ์

```ts
isBalanced("()")       // true
isBalanced("([]]")     // false
isBalanced("([{}])")   // true
isBalanced("([[{}]]]") // false
isBalanced(")")        // false
isBalanced("(]}])")    // false
isBalanced("([)]")     // false
isBalanced("{")        // false
```

## คำอธิบายแนวคิด
ใช้โครงสร้างข้อมูลแบบ Stack:
1. เมื่อพบวงเล็บเปิด ให้เก็บไว้บน Stack
2. เมื่อพบวงเล็บปิด ให้ตรวจสอบว่าสัญลักษณ์บนสุดของ Stack เป็นคู่ที่ตรงกันหรือไม่
3. หากไม่ตรงกันหรือ Stack ว่าง ให้คืน `false`
4. เมื่ออ่านครบทุกตัวแล้ว จะสมดุลก็ต่อเมื่อ Stack ว่าง

ตัวอย่าง `"([{}])"` เปิด `(`, `[`, `{` ตามลำดับ แล้วปิด `}`, `]`, `)` ในลำดับย้อนกลับ จึงได้ `true`
