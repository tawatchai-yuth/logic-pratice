# ข้อ 3: Run-Length Encoding — ย่อข้อความที่มีตัวอักษรซ้ำติดกัน

## ระดับ
ง่าย–ปานกลาง

## โจทย์
เขียนฟังก์ชัน `compress(value: string): string` เพื่อย่อข้อความโดยแทนตัวอักษรที่ซ้ำติดกันด้วยตัวอักษรและจำนวนครั้ง

ตัวอย่างเช่น `"aaabbc"` จะกลายเป็น `"a3b2c1"`

เงื่อนไข:
- นับเฉพาะตัวอักษรที่ซ้ำติดกัน
- ตัวอักษรที่ไม่ซ้ำก็ต้องแสดงจำนวน `1`
- หากผลลัพธ์ที่บีบอัดยาวกว่าหรือเท่ากับข้อความเดิม ให้คืนข้อความเดิม

## ตัวอย่างผลลัพธ์

```ts
compress("aaabbc")       // "a3b2c1"
compress("abcd")         // "abcd"
compress("wwwwaaadexxxxxx") // "w4a3d1e1x6"
compress("")             // ""
compress("aabcccccaaa")  // "a2b1c5a3"
```

## คำอธิบายแนวคิด
ให้เก็บตัวอักษรปัจจุบันและจำนวนครั้งที่พบ เมื่ออ่านตัวอักษรถัดไป:
- ถ้าเหมือนตัวปัจจุบัน ให้เพิ่มตัวนับ
- ถ้าไม่เหมือน ให้บันทึกตัวอักษรพร้อมจำนวน แล้วเริ่มนับตัวใหม่
- เมื่อจบข้อความ ให้บันทึกกลุ่มสุดท้ายด้วย

จากนั้นเปรียบเทียบความยาวของผลลัพธ์กับข้อความเดิมตามเงื่อนไข

## สิ่งที่ควรฝึก
- การวนลูป string
- การตรวจจับกลุ่มตัวอักษรที่ติดกัน
- การจัดการตัวแปรนับจำนวน
- กรณีข้อความว่าง
