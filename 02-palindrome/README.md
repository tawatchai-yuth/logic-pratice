# ข้อ 2: Palindrome — ตรวจสอบข้อความกลับหน้าแล้วเหมือนเดิม

## ระดับ
ง่าย

## โจทย์
เขียนฟังก์ชัน `isPalindrome(value: string): boolean` เพื่อตรวจสอบว่าข้อความอ่านจากซ้ายไปขวาและขวาไปซ้ายเหมือนกันหรือไม่

เงื่อนไข:
- ไม่สนใจตัวพิมพ์เล็กและตัวพิมพ์ใหญ่
- ให้ละเว้นช่องว่าง
- ในชุดฝึกนี้ให้ละเว้นเครื่องหมายวรรคตอนด้วย

## ตัวอย่างผลลัพธ์

```ts
isPalindrome("level")                         // true
isPalindrome("RaceCar")                       // true
isPalindrome("A man, a plan, a canal: Panama") // true
isPalindrome("hello")                         // false
isPalindrome("Was it a cat I saw?")           // true
isPalindrome("programming")                   // false
```

## คำอธิบายแนวคิด
ข้อความจะเป็น palindrome เมื่อข้อความที่ผ่านการปรับรูปแบบแล้วเหมือนกับข้อความเดียวกันที่กลับลำดับตัวอักษร

ตัวอย่าง `"RaceCar"` เมื่อเปลี่ยนเป็นตัวพิมพ์เล็กจะได้ `"racecar"` และเมื่อกลับลำดับก็ยังเป็น `"racecar"` จึงคืนค่า `true`

ก่อนเปรียบเทียบต้องกำหนดให้ชัดว่าจะจัดการช่องว่างและเครื่องหมายอย่างไร โจทย์นี้กำหนดให้เก็บไว้เฉพาะตัวอักษรและตัวเลข แล้วเปลี่ยนเป็นตัวพิมพ์เล็ก

## สิ่งที่ควรฝึก
- การจัดการ string
- `toLowerCase()`
- การกรองตัวอักษร
- การกลับลำดับข้อความ
