# ข้อ 12: Tribonacci — สร้างลำดับจากผลรวม 3 ค่าก่อนหน้า

## ระดับ
ง่าย–ปานกลาง

## โจทย์
เขียนฟังก์ชัน `tribonacci(signature: number[], n: number): number[]` โดย `signature` เป็นค่าเริ่มต้น 0–3 ค่า และ `n` คือจำนวนสมาชิกทั้งหมดที่ต้องการในผลลัพธ์ โดยนับสมาชิกเริ่มต้นรวมด้วย

เมื่อมีค่าเริ่มต้นครบ 3 ค่า สมาชิกถัดไปจะเท่ากับผลรวมของสมาชิก 3 ตัวก่อนหน้า

กติกาเพิ่มเติมสำหรับกรณีค่าเริ่มต้นมีน้อยกว่า 3 ค่า:
- ถ้า `n` ไม่เกินจำนวนสมาชิกเริ่มต้น ให้คืนเฉพาะ `n` ตัวแรก
- ถ้ามีสมาชิกเริ่มต้น 0 ค่า ให้คืน `[]` สำหรับทุกค่า `n`
- ถ้ามีสมาชิกเริ่มต้น 1 หรือ 2 ค่า และต้องสร้างสมาชิกเพิ่ม ให้ใช้กติกาที่กำหนดในโจทย์ฉบับนี้: ยังไม่สามารถคำนวณสมาชิกใหม่ได้ จึงคืนค่าเริ่มต้นเท่าที่มี โดยไม่เพิ่มสมาชิก

## ตัวอย่างผลลัพธ์

```ts
tribonacci([1, 3, 5], 5)  // [1, 3, 5, 9, 17]
tribonacci([2, 2, 2], 3)  // [2, 2, 2]
tribonacci([10, 10, 10], 4) // [10, 10, 10, 30]
tribonacci([5, 2, 0], 0)  // []
tribonacci([1], 1)        // [1]
tribonacci([1], 4)        // [1]
tribonacci([], 5)         // []
```

## คำอธิบายแนวคิด
เริ่มจากคัดลอกค่า `signature` เพื่อไม่แก้ไข array ที่ผู้เรียกส่งเข้ามา จากนั้นวนลูปจนกว่าจะได้จำนวนสมาชิกตาม `n` โดยคำนวณผลรวมของสมาชิก 3 ตัวท้ายและเพิ่มลงในผลลัพธ์

ตัวอย่าง `[1, 3, 5]`:
- สมาชิกถัดไปคือ `1 + 3 + 5 = 9`
- สมาชิกถัดไปคือ `3 + 5 + 9 = 17`

จึงได้ `[1, 3, 5, 9, 17]`

## สิ่งที่ควรฝึก
- การวนลูปตามจำนวนที่ต้องการ
- การเข้าถึงสมาชิกท้าย Array
- การจัดการ input ที่มีสมาชิกเริ่มต้นน้อยกว่า 3 ค่า
